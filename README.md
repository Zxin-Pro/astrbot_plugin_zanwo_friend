## 📦 插件简介

【仅QQ】QQ名片赞，同时用户可以订阅点赞，订阅后bot每天自动为用户点赞。可在 控制面板>插件配置 开启白名单群聊, 开启后只有在白名单群聊中才能使用插件。

> 本仓库基于 [Futureppo/astrbot_plugin_zanwo](https://github.com/Futureppo/astrbot_plugin_zanwo) 修改，遵循原 MIT 协议。
> 主要改动：新增「仅好友可点赞」校验 —— 非 bot 好友会被拒绝，回复「非好友不能点赞」；可在 控制面板>插件配置 中关闭。

## ⌨️ 命令

|     命令      |      说明        |
|:-------------:|:------------------------------------:|
|     赞我       | 给用户点赞（可不带前缀）  |
|     赞@XXX       | 给用户点赞，可以同时@多个人  |
| /订阅点赞      | 订阅后bot每天自动为用户点赞    |
| /取消订阅点赞   | 取消订阅后bot每天不再自动为用户点赞 |
| /订阅点赞列表   | 查看当前订阅点赞的用户ID列表 |
| /谁赞了bot      | 查看谁赞了bot |

## 📌 注意事项

- 默认仅好友可点赞，非好友会回复「非好友不能点赞」；可在 控制面板>插件配置 里关闭 `仅好友可点赞`
- 点赞限制：非好友每天只能点50人，每人50个赞

## ❓ 常见问题

### Q: 为什么点赞失败？

- 可能是因为用对方隐私设置未开启陌生人点赞权限，
- 或者已达到QQ点赞次数限制
- 或者是你没加bot好友，而bot今日给陌生人点赞量也已到达上限
